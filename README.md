# Rust for Experienced Programmers

A Rust tutorial for C, C++, and Python programmers. In Lesson 00, you'll write Hello World and a program that counts readings above a limit.

Start here to install the tools and create your first Cargo project. [Lesson 00, part 1](host/00-rust-orientation/01-first-program.md)

[Lesson overview](host/00-rust-orientation/README.md) · [Linux setup](docs/setup-linux.md) · [Windows with WSL](docs/setup-wsl.md) · [Docker setup](docs/docker.md)

## Run the finished example

Run these commands from the repository root.

```sh
cd host/00-rust-orientation
cargo run
```

The program prints `Readings above 25: 1`. [Example source](host/00-rust-orientation/src/main.rs)
