# Lesson 00. Write your first Rust program

Create a Cargo project, run Hello World, and write a program that counts readings above a limit. You'll edit the same `src/main.rs` file in your `hello_rust` project throughout the lesson.

1. [Cargo, files, and Hello World](01-first-program.md)
2. [Functions and variables](02-functions-and-variables.md)
3. [Readings and control flow](03-readings-and-control-flow.md)

To run the supplied readings program, open `host/00-rust-orientation/` in your terminal and run `cargo run`. It prints `Readings above 25: 1`. [Finished Rust program](src/main.rs)

In that directory, `cargo run --example hello_world` runs the Hello World example. The earlier Rust examples and the C++ and Python files live in `examples/`. [Example files](examples/)
